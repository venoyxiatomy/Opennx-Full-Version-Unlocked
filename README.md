## Overview
<a id="overview"></a>

OpenNX is a desktop virtualization and remote access software developed to replace NoMachine NX. It provides an efficient solution for users looking for reliable remote control capabilities on the Windows platform. OpenNX is designed for those who require seamless access to their desktop environments, even from remote locations. ## Main Features
<a id="main-features"></a>

### Core Functionality
- **Remote Access** — OpenNX allows users to connect to their desktop from anywhere, providing full control over files and applications.
- **Desktop Virtualization** — Users can create and manage virtual desktops, making it easier to access multiple environments simultaneously.
- **SSH Connections** — Secure connections are facilitated through the OpenSC framework, which includes SmartCard authentication for enhanced security.
- **Proxy Support** — OpenNX supports various proxy types, allowing flexible configurations to suit individual network requirements.
- **Dynamic Library Usage** — The software dynamically uses libraries like libsmbclient and pulseaudio, ensuring no static dependencies for a lightweight installation.

### Advanced Capabilities
- **HTTP Configuration Search** — Users can efficiently search for session configuration files via HTTP, streamlining the setup process.
- **Configuration Control Management** — OpenNX allows for the deactivation of configuration controls by reading a single file, simplifying user experience.
- **Performance Optimization** — The use of libjpeg-turbo enhances performance by speeding up image processing wherever possible.
- **Wide Compatibility** — Compatible with both the original NoMachine client and its own setup, enabling a smoother transition for existing users.
